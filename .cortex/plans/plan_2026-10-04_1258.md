## Context

**Explored:** Current `app.py` (208 lines, 5 tabs), all GOVERNANCE/ONTOLOGY tables, Cortex Agent response structure, SiS library availability, `_snowflake` API capabilities.

**Key findings:**
- `DATA_AGENT_RUN` works via `session.sql()` and returns tool call names + SQL + text + ContractSearch results in a structured JSON. This means we can call the **full agent** (not just Analyst) from the Ask tab and get cross-domain answers with contract evidence.
- `_snowflake.send_snow_api_request` is also available for the Analyst-only path but is unnecessary — the agent subsumes it and adds ContractSearch.
- Warehouse runtime supports: `st.graphviz_chart`, `st.altair_chart` (altair is pre-installed), `st.cache_data`, `st.bar_chart`, `st.line_chart`, inline HTML/CSS via `st.markdown`. No `st.set_page_config(page_icon=...)` in Native Apps but works in standalone SiS.
- `st.tabs` is the navigation mechanism (clean top nav).
- Masking cannot be demonstrated live (owner's rights + DEFAULT_SECONDARY_ROLES='ALL'). The ROLE_VISIBILITY_SNAPSHOT approach is correct.

**Agent integration decision:** Use `DATA_AGENT_RUN` for the Ask tab. Parse the response JSON to extract: (1) text blocks for the answer, (2) `system_execute_sql` tool_result for the SQL, (3) ContractSearch tool_results for DOC- citations, (4) tool_use entries for the "tools used" badge. Fall back gracefully if the agent times out.
